You can now search the Key Binds menu for several things at once. Separate them with `|`, as in `Inventory Plus | Hotbar Pockets`, and the list shows every keybind that matches any of them.

Requires MenuKit 7.1.0 or newer, below 8.0.0.

For mod developers: the API adds `openModKeybinds`, which opens the Key Binds menu filtered to one mod or a list of mods, and `hasKeybinds`, which says whether a mod has any keybinds.
